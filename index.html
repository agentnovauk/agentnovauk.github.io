Ground truth

The specification defines intended behaviour; the implementation is diffed against it.

Provenance

Every chunk carries doc-id, release, clause, page and content-hash. The clause number is the citation key.

Deterministic graph

Taint paths come from the code property graph, queried, not guessed by the model.

On rejection: scope gate

Blocked at network, OPA and MCP, and logged; no target is contacted.

On rejection: faithfulness

Citation fails the NLI check; the finding is dropped and never reaches a reviewer.

On rejection: sign-off

The reviewer declines; the finding is returned with notes and is not released.

Enforcement06 / 09

Scope held in infrastructure, not the model

Assembled from established, inspectable components. The boundary holds independently of the model, including one whose refusals have been removed.

01

Network containment

Default-deny egress through a filtering proxy; per-agent scoped networks allowlist only the signed target ranges, enforced by the OS and CNI.

02

Policy engine: OPA / Rego

Every tool call is checked against declarative, version-controlled policy: target in scope, action per persona, clearance. Each decision is logged.

03

Kernel isolation

Agents run in gVisor or Firecracker microVMs, so containment sits at the kernel boundary, not merely the namespace.

04

MCP tool gateway

Each tool (scanner, Joern query, retrieval) sits behind an MCP server enforcing the policy and allowlist, uniform across agents and personas.

An adversarial scope-escape suite runs at install as a release-blocking gate, verified identically on every supported runtime.
